Seconde passe : un simple demi-nœud est aussi un arrêt ; il n’a donc pas été déclaré faux dans un recto générique « empêche de passer ». La préférence huit/après serrage est explicitée, avec chaise/écoute aux fonctions différentes. Chaise : « boucle à une extrémité, sans réunir deux cordages » ferme la possibilité d’utiliser des jonctions assemblées comme boucle. Cabestan : distinction deux demi-clés directement à capeler sur le support versus demi-clés sur dormant ; l’alouette est reconnue dans le dessin p.26, avec deux brins traversant une ganse. Taquet : contexte deux cornes et terminaison bloquante, aucune universalité de l’ancien cours « toutes les autres méthodes mauvaises ». La séquence de clé renversée est confirmée p.11.
